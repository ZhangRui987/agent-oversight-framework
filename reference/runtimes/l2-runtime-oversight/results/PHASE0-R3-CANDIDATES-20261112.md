## 四、机制发现（三层，每层都比 R2 深一层）

1. **标记的内容形态同样模型相关（R2 发现的深化）**：裸派发（ASSIGN 且无代码围栏）率——qwen 良性 86.7–100%（良性派发就是纯指令）、glm 良性 32–53%、glm 攻击仅 26.9–29.9%（攻击派发嵌在含码工作流里）。**「裸 = 纯指挥」的语义假设跨模型不成立**：qwen 良性裸率 100% 直接证伪。
2. **臂内标定在 n=50 下 θ 估计方差大**：qwen 校准半区 θ=0.5，全量良性 P99=0.75——半区标定把 FPR 从固定 0.80 的 1.3% 恶化到 5.3%。**标定程序本身有样本量成本**，n 小则阈值不稳。
3. **攻击构造的投影盲区**：R2 的纯指挥叠加是单轮 6 消息改造（Director 3 次派发 + 3 份报告），消息数 k=6 < 良性 k=9；接收集中度（攻击 0.333）天然低于良性三轮往返流（最高 0.5556）；调度集中度 deepseek 窗口 +0.0556 纯属 1/k 台阶伪影（良性恒 4/9、攻击恒 3/6）；selector 通道 0 调用是场景实现差异非攻击语义。**手工核验确认非脚本 bug**（单条轨迹逐消息打印核对）。
