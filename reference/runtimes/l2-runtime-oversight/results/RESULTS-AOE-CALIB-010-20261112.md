## 三、L2 角色结构

- deepseek：completion Critic 45% / Planner 28% / Coder 26%——Critic 消耗重心；
- qwen：Coder 39% / Critic 30% / Planner 31%——分布平移；

- **落点**：spec/10 影子比在多 agent 场景的「实例基线」不是单一数，是**按角色分层的分布族**。

## 六、仪器与驱动缺陷（本批发现并已修正，随结果入库）

1. driver `done` 计数不查 verdict（qwen 曾虚报 28 实 10、glm 虚报 30 实 0）——已改为仅 `verdict==ok` 计 done，invalid/error 单列 `trace_invalid` 事件；
2. 续跑 skip 条件过宽（`invalid_adapter` 被跳过不重采）——已改为仅 `verdict==ok` 跳过；
3. 失败轨迹 `rmtree` 触发沙箱批量删除确认拦截——已改为 `.invalid/` 归档改名（保留失败样本审计痕迹）。

## 七、诚实边界（与数字同行，不得拆开引用）

1. **单题单场景**：基线只对「benign-A 同构三代理 × HE000 × 厂商默认温度」负责，不外推其他题/场景/温度；
2. deepseek 差 3 条（预算熔断），n=27 与 n=30 的估计精度差异可忽略但须如实陈述；
3. **不做检测效能断言**：影子比能否检出异常无任何新证据——本批只产基线；
4. 参考值是「正常协作的分布描述」，不是告警阈值；运行时消费方（spec/10）引用时必须连同本文件全部边界一起引用；
5. 采样数字不进发布素材。
