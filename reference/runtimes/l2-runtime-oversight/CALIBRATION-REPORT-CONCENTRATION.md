## 1. 实验目的

把 AOE-SWARM-001 的关键发现（S1 对主从调度器形态误报 4/4 = 100%）转化为**可操作的阈值建议区间与主从共存权衡曲线**，为未解问题 #3（阈值标定）落地合成标定中间步。

三个研究问题：

- **RQ1**：S1 在合成分布上的判别力（AUC）是多少？
- **RQ2**：是否存在「常规良性零误报 + 恶性 TPR ≥ 90%」的阈值区间？
- **RQ3**：兼容主从调度器架构（FPR = 0）要求阈值不低于多少？TPR 损失多少？

**定位声明（预注册 §一）**：本实验是**合成分布内的标定，不是** spec/07 §阈值标定前置条件要求的「真实多 Agent 业务」标定——不得据本实验启用硬熔断；#3 推进为「合成标定已落地」，**不闭合**。

## 2. 实验环境与方法论

| 维度 | 值 |
|---|---|
| Node.js | v22.22.2，win32/x64，`--experimental-transform-types` |
| 样本 | 600 条程序化多 Agent 消息日志：M 恶性梯度 8 档（10.5% / 12% / 15% / 20% / 25% / 30% / 40% / 60%，档内 +0–3pp 微扰）× 50 = 400；B1 常规良性 100（单节点 ≈1%–3.9%）；B2 主从调度器 100（20%–40% 均匀） |

### 3.2 RQ1 判别力：AUC 的分层分解（本实验的核心发现）

| 对比 | AUC（Mann-Whitney 精确法） | 读法 |
|---|---|---|
| M vs B1（常规良性） | **1.0000** | **完全分离**——B1 最大占比 3.86% < M 最小占比 10.53% |
| M vs B2（主从调度器） | **0.3586（< 0.5）** | 主从与高集中度恶性**不可分且方向相反**——B2 占比高，比恶性更像「恶性」 |
| M vs B_all（合并保守口径） | 0.6793（精确）/ 0.6744（脚本梯形网格近似） | 混入主从部署后判别力崩塌 |

**H1 ❌ 不成立**（预注册标准 AUC > 0.9；合并口径实测 0.6744 / 0.6793）。但分层分解显示：**失效完全源于部署形态先验缺失，不是信号本身**——在「部署内无主从调度器」的条件下 S1 判别力完美（AUC = 1.0）；问题转化为「部署里有没有调度器」这一先验知识的有无。⚠️ 按 A 级纪律，H1 判定不粉饰：合并口径不成立是本轮的否定性结果，双登记解释见 §5。

### 3.3 RQ2 最优区间：H2 ✅ 成立

「FPR_conv = 0 且 TPR ≥ 90%」区间：**θ ∈ [0.04, 0.12]**。

- 现行阈值 **0.10 落在区间内**——在「部署内无主从调度器」的前提下，spec 的 >10% 阈值**合理**（常规良性零误报、恶性检出 ≥ 93.8%）。
- Youden J 最优 θ* = 0.04（TPR 100%，FPR_all 50%——FPR 全部来自主从形态）；若部署确认无调度器，θ 可下探至 0.04 而不产生常规误报。
- 建议区间表述：**无主从部署 θ ∈ [0.04, 0.12]（下限越低检出越早，上限 0.12 为 TPR ≥ 90% 的边界）；现行 0.10 处于区间内偏保守位置**。

### 3.4 RQ3 主从共存权衡：H3 ✅ 可量化（预注册预期情形定量确认）

- FPR_ms = 0 的最低阈值 **θ_ms = 0.40**（B2 最大占比 39.9% 之上）。
- 该阈值下 TPR = **25.0%**（TPR 损失 **75.0pp**）——且按预注册 H3 预期情形成立：**θ_ms ≥ 0.40，兼容主从则信号对 20%–40% 集中度区间失明**（该区间恰为 B2 全部样本与 M4/M5/M6 三档恶性 150 条的所在）。
- 结构性结论：**不存在同时满足「检出 20%–40% 恶性集中度」与「主从调度器零误报」的单一阈值**——两者的占比区间重叠（恶性 20%–40% 档 vs 主从 20%–40%），单阈值在数学上不可分。

## 4. 判定汇总（预注册标准完整执行）

| 假设 | 预注册标准 | 实测 | 判定 |
|---|---|---|---|
| **H1** AUC > 0.9 | 合并口径 AUC > 0.9 → 成立；> 0.99 强成立 | 0.6744（梯形）/ 0.6793（精确） | ❌ **不成立**——双登记：分层 AUC(M vs B1) = 1.0000，失效源于主从形态混入而非信号本身 |
| **H2** 零误报高检出区间存在 | 存在 θ* 使 FPR_conv = 0 且 TPR ≥ 90% | θ ∈ [0.04, 0.12]，现行 0.10 在区间内 | ✅ **成立** |
| **H3** 主从共存权衡可量化 | 报告 θ_ms 与 TPR 损失；θ_ms ≥ 0.40 如实报「失明」 | θ_ms = 0.40，TPR 损失 75.0pp，失明情形定量确认 | ✅ **成立** |

## 5. 核心结论与治理含义

1. **S1 不存在单一可用阈值——它的可用性条件是部署形态先验**。无主从部署：θ ∈ [0.04, 0.12]（现行 0.10 合理）；含主从部署：单阈值结构性不可用（θ_ms = 0.40 使信号失明）。
2. **治理条款方向（供 spec/07 §阈值标定前置条件的后续条款化参考）**：S1 告警须与**部署形态登记**（合法调度器节点白名单）联合使用——白名单豁免后对其余节点仍可用 [0.04, 0.12] 区间阈值；无白名单机制的部署，S1 输出只能作为线索不得作为判定依据（与 spec/07 §沟通层检测的盲区「只作线索不作判定」的设计要求同构）。
3. **本实验不满足 spec 前置条件**：合成标定 ≠ 真实多 Agent 业务标定；硬熔断保持禁用；#3 推进为「合成标定已落地、真实业务标定仍缺」。
4. **对 SWARM-001 的校准回看**：SWARM-001 的 100% 主从误报不是检测器缺陷，而是「单阈值 + 无形态先验」的结构性必然——本实验给出了定量边界（0.40 以上才零误报）。

## 6. 偏差与执行记录（预注册纪律）

1. **AUC 双口径**：脚本内 AUC 用阈值网格梯形近似（0.6744），报告补充 Mann-Whitney U 精确法（0.6793）——网格近似在低 FPR 区分辨率不足导致 0.0049 偏差；两口径结论一致（均 < 0.9），判定不受影响。此为方法口径补充记录，非规则改动。
2. **脚本笔误一处**：汇总打印的 filter 回调参数笔误（`(_, i)` 误用，运行时报 ReferenceError）——修正为 `(row, i)` 后一次通过，样本构造与统计逻辑零改动。
3. **无其他执行偏差**：预注册样本构造、阈值网格、判定标准逐条执行。

---

## 7. 诚实边界（预注册 §六六条全部适用）

1. **合成分布内有效**——不满足 spec 前置条件的「真实多 Agent 业务」要求；不得据此启用硬熔断；建议区间不得直接移植到真实部署。
2. **恶性侧均匀分布假设**——真实攻击者集中度分布未知。
3. **主从形态一阶近似**——真实框架消息构成更复杂。
4. **单信号标定**——S2/S4 为结构检查无连续阈值；S3 留待扩展。
5. **词表依赖**——任务分配类型识别沿 SWARM-001 冻结词表。
6. **固定种子**——重跑逐位一致。

## 9. 影响与反哺

1. **spec/07 §阈值标定前置条件补「合成标定落地（v2.37.0）」段（中英）**：建议区间 [0.04, 0.12]（无主从部署）+ 主从共存权衡曲线（θ_ms = 0.40 / TPR 损失 75pp / 20%–40% 区间失明）+ 「S1 须与部署形态登记联合使用」的条款化方向。
2. **spec/13 #3 更新（中英）**：合成标定已落地（数字），真实业务标定仍缺——#3 保持未解但缓解升级。
3. **REFERENCES +1 条 A 级**（【键： AOE-CALIB-003】），证据总数 169→170（A:7→8）。
4. **对 G8 的输入**：若后续实现 G8 演示级闭合（告警侧），S1 阈值配置应采用「白名单豁免 + 区间阈值」形态而非裸阈值——本实验的 H3 是其设计约束。
5. **后续钩子**：S3 增速阈值标定（同范式）、多信号联合判别（S1 × 部署形态登记的 2×2 析因）。
