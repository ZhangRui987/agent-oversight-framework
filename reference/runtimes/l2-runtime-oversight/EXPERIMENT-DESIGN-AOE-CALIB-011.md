## 〇、要回答的唯一问题

**per-agent 影子比的正常分布，其方差主要来自「题」还是来自「运行」？——这决定基线该按题标定、还是可以按任务族合并标定。**

CALIB-010 只在单题（HE000）拿到 30 repeat，题间方差与运行间方差无法分离；CALIB-009 pilot K4 的定性观察（「HE020 一题把 Coder/Planner 同时抬高」「正式标定须同题跨 repeat」）指向题间方差显著，但 n=3 不算数。本条用受控设计把两个方差源拆开。**不做、也不声称任何检测效能。**

## 一、冻结设计

### 1.1 采样矩阵（81 条）

- **臂**：deepseek（deepseek-chat）/ qwen（qwen-flash）/ glm（glm-4-flash），厂商默认温度（沿 R1/R2/CALIB-010 实跑口径，不设 temperature）。
- **场景**：benign-A 同构三代理（Coder/Critic/Planner + selector），**AutoGen 单框架**（跨框架对照已由用户裁决剔除，须另立预注册）。
- **题池**：`task-pool-humaneval-r2.json` **题序前 9 题**（HE000 / HE003 / HE020 / HE021 / HE027 / HE051 / HE057 / HE067 / HE076；题序位置登记，与任何消耗数据无关，防选择性偏差）。
- **repeat**：每题 r=3。
- 顺序：arm-major（deepseek → qwen → glm），题内 rep 1→3；driver 可续跑。

### 1.2 仪器与驱动（零改动承诺）

- 采集沿 CALIB-009/010 仪器：`ClientBundle` 逐 agent 计量 + 九字段 `ledger-events.jsonl` + `ledger_invariant` 覆盖检查。**任何仪器改动 = 本预注册整体作废、版本号递增、重跑全量**（沿 CALIB-007 决策 27 条款）。
- 驱动：`scripts/c011_calibration_driver.py`（自 c010 driver 派生：加题维循环；**继承全部缺陷修正**——只跳过 `verdict=="ok"`、失败轨迹 `.invalid/` 归档改名不删除、timeout 600s）。
- 分析：`scripts/c011_analyze.py`（ρ 计算 + 区间化 + bootstrap，见 §二）。
- 输出隔离 `adapters/autogen/out/run-20261113-c011/`，不复用 R2/c010 目录。

### 1.3 预算（冻结）

- 单臂熔断 **750K**（期望 ≈9 题 × 3 repeat × ≈21K ≈ 570K/臂）；全局熔断 **2.2M**（跨臂累计，driver 经共享预算文件逐条检查）。
- 超限即停，缺额如实登记「未采完」。**正式的跨框架 / 跨场景标定不在本预注册内。**

## 二、冻结判据

**口径（全部沿 CALIB-010）**：观测值 = per-agent completion tokens；影子比参考 = k3 / 中位（k3 = 中位 + 3 × 1.4826 × MAD）。

- **M1（方差分离，本条核心）**：对每个「模型 × 角色」账——
  - **组内离散度**（运行间）：同 (arm, task, agent) 跨 3 repeat 的 MAD；组内代表值 = 9 个题的组内 MAD 的中位；
  - **组间离散度**（题间）：同 (arm, agent) 跨 9 题的「题内中位」的 MAD（先用题内中位消除运行间方差，再对题中位序列算 MAD）；
  - **ρ = 组间MAD / 组内MAD代表**，判读带（预注册冻结，防事后解读）：
    - ρ ≥ 2 ⇒ 题间方差主导 ⇒ **基线必须按题（或题难度档）分化，任务族合并标定不可行**；
    - 0.5 ≤ ρ < 2 ⇒ 两源同量级 ⇒ 合并标定可行性**登记为开放**，需更大样本另行判定；
    - ρ < 0.5 ⇒ 运行间方差主导 ⇒ 跨题合并基线可行（按 CALIB-010 方式扩展题数即可）。
  - 任一方向都是有效结果，不预设结论。
- **M2（区间化）**：每「模型 × 角色」合并 9 题 × 3 repeat = 27 点（与 CALIB-010 n 对齐）：P10–P50–P90 分位 + k3/中位参考 + bootstrap 10,000 次 95% CI；**全部为分布登记，不是阈值，spec/10 默认阈值 2.0 不变**；与 CALIB-010 单题参考值并列对照登记（漂移量即题效应的直接读数）。
- **M3（跨题跨度对照）**：跨题「题中位」的 max/min 比，与 CALIB-001 一致性判据 0.15 作**描述性对照**（不判定通过与否，只登记量级）。
- **M4（MAD 退化检查）**：沿 CALIB-010 条款——组内 MAD=0 或题中位恒值的账如实登记「信号被架空/小样本伪影」，不冒充。

## 三、翻车分支（全部为合法判定）

| 情形 | 判定 | 动作 |
|---|---|---|
| 预算熔断 | 已采部分照常判定，缺额记「未采完」 | 不挪用他人结论补叙事 |
| 某臂 API 中途不可用 | 该臂记「未采完」 | 可续跑补采（沿 CALIB-010 先例）；跨臂比较须等全臂收齐 |
| K1 不变量差 > 0 或覆盖缺口 | 仪器缺陷 | ERRATA 后重采，不得就地修补 |
| MAD 退化 | 「信号被架空/小样本伪影」 | 如实登记，换维度兜底另立预注册 |
| max_tokens 截断类方差为零 | 「信号被配置架空」 | 按 CALIB-001 先例登记 |

## 四、诚实边界（随结果同行，不得拆开引用）

1. 本条产出的是**分布与方差结构**，不是检测器；「影子比可检测多 agent 异常」仍无任何新证据；
2. 81 条 × 3 agent 的样本量支持 M1–M4 的登记，**不支持任何阈值声明**——参考区间不是告警线；
3. 单场景（benign-A）、单框架（AutoGen）、厂商默认温度——外推须另立预注册；
4. 与 spec/13 #33 的关系：本条标定的是 spec/10 影子比的 per-agent 分布面；**spec/09 四类运行时阈值（步数/频次/时长/资源）的按任务族全谱标定是另一条线，不在本条内**——若 M1 结论为题间主导，对四类阈值线的方法论启示（阈值须按任务类型分化）只作注记级引用，不并案。
