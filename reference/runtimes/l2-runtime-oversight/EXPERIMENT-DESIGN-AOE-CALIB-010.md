## 〇、要回答的唯一问题

**正常多 agent 协作（benign-A 同构三代理）中，每个 agent 的消耗（completion / prompt / calls）在同一题同一模型上的运行间方差分布是什么？MAD + k 阈值参考值是多少？**

产出是**基线数据**——「正常协作的 per-agent 消耗基线 + 阈值参考」，供 spec/10 影子比信号在多 agent 场景的运行时核算使用。**不做、也不声称**任何检测效能。

## 一、设计要点（从 pilot 实测教训直接推出）

1. **同题跨 repeat 是科学前提**（pilot K2 缺口的正解）：pilot 实测 glm 同一 agent 跨题 completion 波动 3.0–8.8×——题间方差与运行间方差混在一起。影子比语义是「同任务偏离基线」，基线必须是**同题**的运行间分布。本设计：单题 × N repeat，纯运行间方差，无混杂。
2. **选题规则冻结、防选择性偏差**：pilot 三题中不按波动结果选题（那会把「难预测的题」或「稳定的题」当基线）。**冻结规则：取 R2 冻结良性题清单第一题 HE000**（题序位置决定，与任何消耗数据无关）。
3. **K2 矛盾的修正落点**：CALIB-009 K2 要求「同题跨 repeat n≥2」但其冻结规模 n=1——本预注册以 N repeat 从结构上满足，并在入库时回填该矛盾的处理记录（CALIB-009 结果文档已登记，不回改）。

## 二、冻结设计

### 2.1 采样矩阵

| 臂 | 场景 | 题 | repeat | 轨迹 |
|---|---|---|---|---|
| deepseek-chat | benign-A | HE000 | 30 | 30 |
| qwen-flash | benign-A | HE000 | 30 | 30 |
| glm-4-flash | benign-A | HE000 | 30 | 30 |
| **合计** | | | | **90** |

- 温度口径：沿 R1/R2/pilot 实跑口径（不设 temperature，走厂商默认）——厂商默认温度下的采样方差正是运行时真实形态。
- N=30 的依据：CALIB-001 用 N=50（单 prompt 单调用）；per-agent 场景每轨迹产出 3 个 agent 账，N=30 ⇒ 每 agent 30 点（90 账/臂级聚合）——MAD 类稳健估计在 n=30 已够登记参考值；50 的增量信息小而成本 +67%。

### 2.2 判据（冻结）

- **L1（主）**：每臂 × 每 agent 的 completion 分布登记 MAD + 1.4826 × k 阈值参考值，k ∈ {2, 3} 两档，附 bootstrap 95% CI（重抽 10,000 次）——**登记值不作检测阈值**（CALIB-001 严格支撑范围条款照搬）。
- **L2（角色结构）**：Coder/Critic/Planner 三角色消耗占比与 calls 分布登记——多 agent 协作的角色消耗结构是影子比「实例基线」的构成部分。
- **L3（跨模型）**：v2.16.0「单阈值不跨模型通用」结论在 per-agent 粒度是否复现——三臂参考值跨度与一致性判据 0.15 比较。
- **L4（MAD 退化检查）**：登记 MAD=0 或近零的账（pilot 已见 qwen 两账 MAD≤1）——按 CALIB-001 先例，方差为零的维度不适合做异常检测，须显式标「信号退化」并登记兜底维度（prompt 或时长）。
- 判据入库后不得修改；不适用 ⇒ 报负结果。

### 2.3 预算（冻结）

- 上限 **2,500,000 token**。估算：pilot 实测均价 deepseek ≈28K/条、qwen ≈14K/条、glm ≈20K/条 ⇒ 30 条/臂 ≈ 0.84M + 0.42M + 0.60M ≈ **1.86M**，余量 0.64M 供重跑。
- 超限即停；缺额如实登记「未采完」。

### 2.4 翻车分支（全部为合法判定）

| 情形 | 判定 | 动作 |
|---|---|---|
| 某臂运行间方差为零（全部 repeat 恒值） | 「该臂影子比信号被架空」 | 按 CALIB-001 先例登记，不冒充有分布 |
| API 中途不可用 | 该臂记「未采完」 | 不补第二家冒充 |
| 仪器缺陷（coverage_ok=false 等） | 全批作废 | ERRATA 后重采 |
| 发现 repeat 间系统性漂移（如上下文累积） | 「同题重跑非独立同分布」 | 如实登记，影响 L1 解释边界 |

## 三、诚实边界（随结果同行，不得拆开引用）

1. **单题单场景**：基线只对「benign-A 同构三代理 × HE000 × 厂商默认温度」负责，不外推到其他题 / 其他场景结构 / 用户自设温度；
2. **不做检测效能断言**：「per-agent 影子比能检测异常」无任何新证据——本预注册只产基线；
3. 攻击检测问题整体挂起（R3 Phase 0 负结果），本采样纯良性侧；
4. CrewAI / LangGraph 不在本预注册内（K3 运行时缺额另行闭环，依赖隔离方案另行裁决）。
