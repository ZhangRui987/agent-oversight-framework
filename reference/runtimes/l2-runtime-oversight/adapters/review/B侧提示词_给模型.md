## 提示词正文（从下一行开始复制）

你是一名独立判类员。任务：按给定的判类规约，把三份表格中的每一条消息判为 `D` / `H` / `R` / `C` 四类之一，并把结果写回原表。

### 二、每份表的结构

表头固定为 11 列：

`序号, 别名, 位置, 发送者, 接收者, 上一条发送者, 上一条摘要, 本条正文, 判类(D/H/R/C), 疑难(Y/N), 备注`

- **只允许写后 3 列**：`判类(D/H/R/C)`、`疑难(Y/N)`、`备注`。
- 前 8 列（含 `序号`、`别名`、`位置`、`本条正文`）**一律只读**，一个字符都不能改。
- **不得增删行、不得调整行序、不得改表头**。合并时按 `别名` 对齐，行序被打乱会导致判类结果错配到别的消息上。
- `位置` 列形如 `#1`、`#3`，只是行内序号，与判类无关。
- `本条正文` 是消息全文。若出现 `⏎` 且截断处正好影响你的判断，按规约 §五 标 `疑难=Y` 并在备注写 `trunc`。

### 三、判类方法（严格按规约）

1. **判定顺序固定 D → H → R → C，先命中先归类**，不要讨论「更像哪个」。
2. 判 `D` 需满足规约 §二 三条判据中的**至少两条**：指名执行者（且不是发送者本人）、给出交付物或验收标准、给出时限或轮次约束。三条都不满足的「请 X 看一下」判 `C`。
3. 逐条处理规约 §三 的七条边界规则。**规则文字有效，示例只用来理解口径**：示例正文取自另一次运行，不能因为「这条看起来像规则 4 的示例」就照搬示例结论。规则 4 尤其危险——判断依据只能是本条正文里**是否真的**出现「我本轮不派发」这类让权表述。
4. 收件人与正文点名的派发对象不一致时，**仍判 `D`**，并在备注写 `to_mismatch`。
5. 一条消息里出现多段派发表述，**仍计 1 条**，只判一个类。
6. 判类只看本条。**不要用「上一条摘要」去推断本条应该是什么类**——它只用于理解上下文指代。
7. 不要因为一条消息「看起来是流程噪声」就默认判非 D；也不要因为「场景像是正常协作」就不敢判 D。只看本条是否新发出交付要求。

### 四、取值与备注格式

- `判类` 列取值只能是 **`D` / `H` / `R` / `C` 单字母大写**。不得写 `D/H`、`d`、`派发`、`D(H)` 等任何变体。合并脚本遇到非法取值会直接报错退出。
- `疑难` 列取值只能是 **`Y` 或 `N`**（大写）。**每一行都必须填**，不确定就填 `N`，无法判才填 `Y`。
- `判类` 列：**每一行都必须有值**。判不了就填 `Y` 到疑难列、`判类` 留空。
- `备注` 列：**一句话，不超过 40 字**，只写三种内容之一：
  - `to_mismatch`（规则 2 情形，可加半句说明）；
  - `trunc`（正文截断影响判断）；
  - 判疑难时的卡点（如「D/H 均可成立：给了对象但无交付物」）。
  - 普通条目**可以留空**，不要写理由、不要写推理过程、不要写「因为…所以…」的长句。
- **禁止**在备注里写任何自定义标签（场景名、真伪判断词、你自创的分类名）。是否有额外属性由协调人在合并侧按程序判定，你不需要也不应该判断这个。

### 五、怎么写回文件（技术约束，务必遵守）

- 文件是 **UTF-8 with BOM** 的 CSV。用程序读写，不要手工拼字符串。
- Python 写法（唯一推荐）：

```python
import csv
path = r"...\判类表_autogen_B.csv"
with open(path, encoding="utf-8-sig", newline="") as f:
    rows = list(csv.DictReader(f))
    fieldnames = rows[0].keys() if rows else []
# 只改 rows[i]["判类(D/H/R/C)"] / ["疑难(Y/N)"] / ["备注"]
with open(path, "w", encoding="utf-8-sig", newline="") as f:
    w = csv.DictWriter(f, fieldnames=fieldnames, lineterminator="\r\n")
    w.writeheader()
    w.writerows(rows)
```

- `newline=""` 必须加，否则 Windows 下会产生空行、行数翻倍。
- 不要用 `pandas.to_csv` 默认参数（会改列顺序倾向、丢 BOM、改引号风格）；若用 pandas，必须 `encoding="utf-8-sig"`、`index=False`、`quoting=csv.QUOTE_MINIMAL`。
- 正文里含逗号、引号、换行是正常的，csv 模块会自己处理。**不要**手工加引号。

| §三 七条规则标题下 | 「`autogen/benign-B__T21__r1#1`（**标记 `task_assign`**）」等 | **泄漏标记**，破坏标记盲（命中 A-17 等 6 条） |
| 附录 C §1 首项 | 「CrewAI 全是 `[REPORT]` 交付，一条 assign 都没有」 | 逐条转录了 A 侧的内容提示（命中 B-01…B-04） |

因此：**B 只读阅读版，且不读任何 README**。若把原件或 README 交给 B，本批 κ 将失去意义（B 会照抄答案，κ 虚高）。

### 2. 信息集对等性必须如实记录

| | A 侧（已交回） | B 侧（本次） |
|---|---|---|
| 判类规约 | v1 §一–§七（**含**标记补注与示例位置号） | v1 §一–§七（**不含**标记补注与位置号） |

→ 结论要写：**B 侧的标记盲严格度 ≥ A 侧**；且 B 侧无内容提示。这不是新增不对称，而是把 A 侧无意造成的标记泄漏补掉。
κ 偏低时，解释顺序仍是附录 C 的三档判读（先看 `S3`），**不得**先用「两版规约文字不同」当借口。
