# 标记/语义双人核对记录 · 模板 v1

> 本文件是**空白模板**。实际记录由 `merge-review.py` 从两份填好的判类表自动生成，
> 生成结果命名为 `核对记录_<批次>.md` 并入库；本模板只定义「必须记录哪些字段」，
> 手工离线核对时照此填写。
>
> 填写纪律：**先填完两份判类表，再打开对方的那份。**任何在合并后修改的格子，
> 须在 §五 分歧日志里留痕并注明修改人。
