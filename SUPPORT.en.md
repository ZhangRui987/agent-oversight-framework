# Support

- **Usage questions**: first look up the relevant section in `spec/`, or search existing Issues.
- **New issues**: submit using the Issue templates (see `.github/ISSUE_TEMPLATE/`).
- **Security and evidence issues**: see `SECURITY.md`.
- **This repository does not provide**: code debugging, deployment implementation, compliance-consulting services.

Maintainer response target: first response to public Issues within 7 working days.
